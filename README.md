# JUVONTRA

Responsive, multilingual concept landing page for JUVONTRA, a proposed worldwide platform for videos, games, creators and a shop.

## Current published preview
The current GitHub Pages site is a front-end concept only. It includes sample public video playback and one playable Tic-Tac-Toe demo. The catalogue cards are examples, not thousands of hosted games.

## Not implemented
Accounts and secure authentication, account recovery, creator video uploads and editing/publishing, game creation/editing/publishing and hosting, shop checkout, a JUVONTRA Coins ledger and creator rewards, anti-cheat, abuse reporting and moderation workflows, backups and production monitoring are not implemented.

## Domain and branding
The website source branding has been changed to JUVONTRA. The repository name and GitHub Pages address still contain ZYNTRA.com. The custom domain juvontra.com has not been purchased or connected; an “Add to cart” message at a registrar is not proof of ownership.

## Enable GitHub Pages
1. Open **Settings** in this repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site and show its URL.

## Languages
English, Spanish, French, German and Portuguese have translations. Other listed languages are selectable but currently fall back to English until translations are added.

## Launch status
This is a prototype, not a production-ready worldwide platform. Before launch, complete cross-device/browser testing, accessibility review, privacy and data-protection review, moderation design and staffing, security testing, backups and restore tests, operational monitoring, and legal/compliance review.
