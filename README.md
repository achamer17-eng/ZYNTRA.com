# JUVONTRA

A responsive, interactive front-end MVP for a worldwide creative platform concept: videos, games, creator tools and a demo shop.

## Try the preview

GitHub Pages preview: https://achamer17-eng.github.io/ZYNTRA.com/

## Working in this front-end demo

- Responsive navigation and layouts for mobile, tablet and desktop screen sizes.
- Video player with selectable public sample MP4 clips.
- Searchable and filterable game catalogue.
- Three playable mini-games: Tic-Tac-Toe against a simple computer opponent, Memory Match and a reaction-time test.
- Creator Studio form that saves draft text to the current browser's local storage and displays the selected file name; it does not upload or render the file.
- Demo Coins, daily demo reward and cosmetic shop items stored in the current browser only.
- Language selector with partial navigation/section translations for English, Spanish, French, German and Portuguese.
- Keyboard focus styling, semantic sections, accessible labels and reduced-motion support.

## Important limits — not a production service

This is an interactive front-end MVP. It is not yet a complete social network or multiplayer platform.

- No user accounts, sign-in, identity verification or account recovery.
- No backend API, production database or cloud file storage.
- Sample videos are served by third-party sample-video hosts; users cannot publish videos.
- The games are local single-player demos; no multiplayer, user-created games, game engine or creator publishing pipeline.
- Creator drafts, demo coins, claimed rewards and shop ownership are stored only in the current browser. They are not real currency, have no cash value and do not sync across devices or accounts.
- No payment processing or real-money checkout.
- No production moderation, abuse reporting, anti-cheat, trust-and-safety operations or content review.
- No verified privacy policy, terms, backup/restore system, monitoring, penetration testing, load testing or independent accessibility audit.

## Branding and domain

The product branding in the website is JUVONTRA. The GitHub repository and GitHub Pages address retain the historical name ZYNTRA.com. The exact domain ZYNTRA.com is not owned or connected by this repository. The candidate domain juvontra.com has not been purchased or connected.

## Development and deployment

The site is a static HTML/CSS/JavaScript application. GitHub Pages can publish it from the repository's configured publishing source. Check the repository's Actions tab and Settings → Pages for the current deployment state and published URL.
