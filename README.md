# ZYNTRA

Responsive, multilingual concept landing page for ZYNTRA.

## Enable GitHub Pages
1. Open **Settings** in this repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site and show its URL.

## Current scope
This is a front-end concept landing page only. Accounts, secure authentication, video uploads/transcoding/streaming, game creation and hosting, marketplace payments, creator rewards ledger, moderation, account recovery, backups and production monitoring are not implemented. ZYNTRA Coins are a planned virtual feature and have no cash value in this preview.

The selector includes English, Spanish, French, German and Portuguese translations. Other listed languages are selectable but currently fall back to English until translations are added.
